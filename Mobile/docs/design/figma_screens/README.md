# 📱 Figma Screen Mockups

Folder ini digunakan untuk menampung tangkapan layar (screenshot/export PNG) dari desain Figma untuk setiap halaman aplikasi Mobile.

## 🤖 Panduan untuk AI Assistant
Saat membuat atau merevisi halaman Flutter di `lib/presentation/pages/<nama_halaman>/`:
1. **Periksa folder ini terlebih dahulu.**
2. Cari file screenshot yang sesuai dengan nama halaman (misal: `home_page.png` atau `05_home.png`).
3. Gunakan tool `view_file` pada file gambar tersebut untuk memahami tata letak visual, proporsi, margin, dan komponen yang diinginkan user sebelum menulis kode widget.
