# Progressio video

30-second Indonesian product explainer, built with Remotion. All visuals are original React/CSS; no external footage, music, or fonts.

```powershell
npm install
npm run dev
npm run render
```

The rendered video is written to `out/progressio-intro.mp4`. Credential visuals are explicitly marked as a demo simulation, not a verified credential.

Remotion's current free license covers individuals and teams of up to three, including commercial use. Recheck the [license terms](https://www.remotion.dev/docs/license) if the usage or team size changes.
