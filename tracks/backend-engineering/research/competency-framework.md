# Competency framework

| ID | Purpose | Learning outcome | Hours | Required competencies |
|---|---|---|---:|---|
| programming_fundamentals | Build reliable program logic | Create a small tested program with clear modules | 32 | — |
| backend_foundations | Understand service behavior | Explain and operate a small HTTP service | 30 | programming_fundamentals |
| database_engineering | Manage durable data | Design and query a consistent relational model | 38 | programming_fundamentals |
| authentication | Protect identity and access | Review and implement a secure identity flow | 30 | backend_foundations |
| api_development | Expose backend capabilities | Design, document and test a versioned HTTP API | 40 | backend_foundations, database_engineering, authentication |
