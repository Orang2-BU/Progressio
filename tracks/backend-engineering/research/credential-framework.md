# Credential framework

## Progressio Backend Engineering Foundations

- Required competencies: all five MVP competencies.
- Required skills: all 16 skills in `skill-graph.md`.
- Passing rules: every knowledge/coding check ≥70; every competency project ≥80.
- Required evidence: repository, test output, API contract, database evidence, security review and final project.
- Metadata: issuer `Progressio`, version `1.0.0`, validity `non-expiring`.
