# Backend Engineering MVP Research Scope

## Target learner

An early-career developer who can use a computer confidently and has written a small program before, but has not yet designed or implemented an HTTP API. The learner is expected to have basic command-line literacy and no prior professional backend experience.

## MVP scope

This research slice defines only three competencies:

1. Programming Fundamentals
2. Backend and Web Foundations
3. API Development

It covers program control flow, functions and modules, Git workflow, the client-server model, HTTP messages and semantics, API contracts, and boundary validation/error behavior.

## Excluded scope

Database engineering, authentication and authorization, automated testing as a competency, deployment, microservices, system design, DevOps, cloud infrastructure, observability, blockchain, frontend implementation, and framework-specific application development are intentionally excluded.

## Entry-level Backend Engineer, for this curriculum

An entry-level backend engineer can turn a small written requirement into a clear API contract and a bounded service behavior. They can choose HTTP methods and status codes deliberately, validate untrusted input, communicate failures predictably, use Git for reviewable changes, and explain the client-server exchange behind an endpoint. They are not yet expected to design data persistence, identity systems, distributed systems, or production infrastructure.
